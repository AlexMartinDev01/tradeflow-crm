# TradeFlow CRM 功能实现状态

> 本文按“前端可操作 + 后端有真实业务逻辑 + 数据可持久化 + 权限/流程有效”作为“已完成”的判断标准，不把只有数据表或通用 CRUD 的功能算作完整实现。

## 当前已经完成的 14 个重点阶段

1. **客户标签 / 客户负责人 / 查重防撞**
   - 客户标签新增、移除、筛选
   - 新建客户自动归属当前用户
   - 管理员/经理可转移客户负责人
   - 公司名、官网域名、税号、注册号、邮箱、电话重复识别
   - 新建客户前撞单提醒

2. **全局搜索 / 高级筛选 / 保存视图**
   - 搜索客户、联系人、联系方式、标签、品牌、自定义字段
   - 国家、状态、等级、负责人、标签、来源、行业、客户类型筛选
   - 保存/应用/删除客户筛选视图

3. **Excel 导入导出**
   - xlsx/xls/csv 解析
   - 自动字段映射
   - 手工字段映射
   - 导入预检
   - 重复识别
   - 新增/更新/跳过决策
   - 正式批量导入
   - 客户 Excel 导出

4. **RBAC 与数据范围**
   - admin / manager / sales / followup / finance / readonly 基础角色
   - 销售/跟进按客户负责人限制数据范围
   - 财务写权限限定在回款/信用
   - readonly 禁止写操作
   - 非管理角色隐藏报价成本/毛利
   - 后端接口权限校验，而非仅前端隐藏菜单

5. **客户 360° 统一时间线**
   - 客户创建
   - 跟进
   - 询盘
   - 商机
   - 报价
   - 样品
   - 合同
   - 订单
   - 回款
   - 出运
   - 售后
   - 按时间统一聚合

6. **自动化与提醒引擎**
   - 逾期回款
   - 报价到期
   - 品牌授权到期
   - 沉默客户识别
   - 自动生成任务并去重
   - 自动化规则开关、阈值、日志、手动立即运行
   - 服务运行期间每 10 分钟自动扫描

7. **订单执行工作台**
   - 订单头信息
   - 产品明细
   - 金额重算
   - 状态推进
   - 变更日志
   - 回款、出运、单证统一查看

8. **回款与信用**
   - 定金/尾款计划
   - 财务登记到账
   - 应收/已收/未收/逾期统计
   - 信用评级
   - 授信额度
   - 账期
   - 信用保险额度
   - 可用授信计算

9. **分批出运与多货柜**
   - 一个订单多个 Shipment
   - 每批 Shipment 可选择部分订单产品和数量
   - 多货柜
   - 柜型、柜号、封条号
   - Booking、Carrier、Forwarder、Vessel/Voyage
   - POL / POD / ETD / ETA / BL
   - 出运状态推进
   - 根据已出货数量自动更新订单状态

10. **PI / CI / PL / Draft BL / Draft CO**
    - PI、CI、PL 系统生成
    - BL、CO 明确生成 Draft，避免冒充承运人/官方签发件
    - 版本号
    - 在线预览
    - 下载
    - 订单单证列表

11. **真实附件系统**
    - 文件实际写入 UPLOAD_DIR
    - 文档元数据存 SQLite
    - 15MB 单文件限制
    - 危险扩展名拦截
    - SHA-256 校验
    - 版本号
    - 预览 / 下载 / 删除
    - 客户附件
    - 订单附件
    - 售后附件
    - Docker 持久化卷已配置

12. **售后与投诉专用流程**
    - 修复 opened_at 必填 bug
    - 自动售后工单号
    - severity
    - 自动 SLA 截止时间
    - open / investigating / awaiting_customer / resolved / closed
    - 责任部门
    - 解决方案
    - 满意度
    - SLA 逾期统计
    - 证据附件

13. **统计分析中心**
    - 客户增长趋势
    - 订单收入趋势
    - 销售漏斗
    - Pipeline
    - 加权商机预测
    - 复购率
    - 来源收入
    - 客户销售额排行
    - 估算毛利
    - 品牌关联客户分布
    - 业务员客户数/跟进数/订单数/收入

14. **营销与外部集成基础**
    - 动态客户分群
    - 邮件模板变量
    - 营销名单快照
    - 无邮箱/退订客户自动跳过
    - 手工退订记录
    - 活动转化归因
    - Webhook 集成配置
    - Webhook HMAC 签名（密钥来自环境变量）
    - Webhook 投递日志
    - API Token 创建/撤销/过期/最近使用
    - API Token 仅创建时返回明文
    - Gmail / Outlook / WhatsApp Business / ERP 等保留安全配置入口，但未获得外部账号授权前不标记为“已接通”

```
→ 跟进 / 任务
→ 询盘
→ 商机
→ 报价
→ 报价版本 / 毛利 / 审批
→ 样品
→ 订单
→ 收款计划 / 回款 / 信用
→ 分批出运 / 多货柜
→ PI / CI / PL / Draft BL / Draft CO
→ 售后 / 投诉
→ 统计分析
```
