# TradeFlow CRM 当前实现状态

> 更新时间：2026-09-26  
> 仓库：`AlexMartinDev01/tradeflow-crm`  
> 主分支：`main`

## 判定标准

只有同时满足以下条件才列为“已实现”：

- 前端有实际操作入口；
- 后端有真实业务逻辑；
- 数据真实持久化；
- 权限在后端校验，而不是只隐藏菜单；
- GitHub Actions Docker 构建通过。

## 当前已完成的重点阶段

### 1. 客户主数据与组织关系
- 客户主档、标签、自定义字段
- 客户负责人、协同人
- 查重与防撞
- 母子公司 / 总部 / 分支组织关系
- 客户合并
- 客户资料完整度评分
- Excel 导入、预检、更新/跳过决策与导出

### 2. 联系人与多渠道触达
- 多联系人、主要联系人、角色/部门
- 联系人离职交接与继任联系人
- 生日/纪念日
- 联系方式多渠道
- 管理员可配置渠道名称、Key、唤起方式、URL/App Scheme 模板和复制回退
- WeChat 等不能稳定深链的渠道支持复制回退，不伪造直接唤起能力

### 3. 品牌与多级渠道网络
- 品牌主数据
- 客户-品牌多对多
- 授权区域、独家、有效期
- 品牌 → 进口商 → 一级/二级经销商/零售商渠道树
- 渠道循环校验

### 4. 客户画像与价值
- 资料完整度
- 订单数
- LTV 按币种统计
- 最近跟进
- 开放商机
- 规则型潜力评分
- 复购分析

### 5. 客户跟进与 360°
- 跟进记录
- 任务
- 下一步
- 客户创建、询盘、商机、报价、样品、合同、订单、回款、出运、售后统一时间线

### 6. 询盘与商机
- 新询盘自动优先分给客户负责人
- 无负责人时按当前未关闭询盘数做负载分配
- 首次响应 SLA
- SLA 超时自动任务
- 询盘转商机
- 商机阶段、金额、概率、竞争对手
- 输单必须记录原因
- won / lost 自动修正概率

### 7. 产品与价格
- 产品/SKU/认证
- 客户兴趣、已报价、已采购、禁售/不适配关系
- 客户专属价目表
- 阶梯价
- 历史报价价 / 成交价
- 国家禁售/认证适配规则
- 产品底价
- HS Code、报关品名、原产国、申报要素

### 8. 可审计汇率
- 人工/外部来源汇率表
- 生效日期
- 直接换算
- 反向换算
- USD 交叉换算
- 产品价格解析可指定目标币种
- 明确区分“企业维护汇率”与“实时市场汇率”

### 9. 报价与审批
- 报价版本
- 产品明细
- 成本/毛利
- 底价红线
- 低毛利阈值
- 高折扣阈值
- OA / D/P / D/A 等特殊付款条件
- 普通报价未触发规则时自动通过
- 风险报价进入审批
- 审批/驳回历史
- 报价转合同/订单

### 10. 样品
- 样品申请、寄送、运单、签收、反馈
- 到货后自动生成反馈任务

### 11. 合同工作台
- 手工合同
- 报价转合同
- 合同 V1/V2/V3...
- draft / pending_signature / signed / active / expired / terminated
- 合同版本历史
- 关联订单
- 合同附件

### 12. 订单执行
- 订单头与明细
- 金额重算
- 状态推进
- 变更日志
- 回款、出运、单证统一查看

### 13. 回款与信用
- 定金/尾款计划
- 财务到账登记
- 应收/已收/逾期
- 信用评级、授信额度、账期
- 信用保险额度

### 14. 分批出运、多货柜与单证
- 一个订单多批 Shipment
- Shipment 分配本批产品和数量
- 多货柜、柜型、柜号、封条
- Booking、Carrier、Forwarder、Vessel/Voyage
- POL / POD / ETD / ETA / BL
- PI / CI / PL
- Draft BL / Draft CO（明确不是正式签发件）

### 15. 结构化报关

- HS Code

- 原产国
- 品牌 / 型号 / 材质 / 用途

### 16. 售后与投诉

### 17. 客户公海与协同

- 公海事件历史

### 18. 部门级 RBAC / 数据范围
- admin / manager / sales / followup / finance / readonly
- self / department / all
- 部门与部门负责人
- 客户、联系人、询盘、商机、报价、订单、出运、售后、报关统一范围

- 动态分群

### 23. 账号与认证安全
- scrypt 密码哈希
- Session
- 全局限流

- 强密码规则
- 管理员重置后强制改密
- TOTP 2FA
- 2FA challenge 过期与失败次数控制

- 修改密码后清理其他 Session

### 24. 回收站
- 客户软删除

- 事务清理关联业务数据与附件元数据

### 25. 数据库备份
- SQLite `VACUUM INTO` 一致性快照
- 管理员手工备份
- 每日自动备份
- 自动保留最近 30 份
- 下载/删除
- 默认备份目录与数据库位于同一个持久化卷
- 离线恢复脚本
- 恢复前自动保存 pre-restore 副本
- 明确提示 uploads 卷仍需独立备份

### 26. 数据隐私与导出安全
- 税号/注册号等客户字段后端脱敏
- Email/Phone/WhatsApp/IM 渠道值后端脱敏
- 完整可见角色
- “仅有客户权限时可看完整值”的角色
- 客户导出角色控制
- Excel 导出强制执行 self / department / all
- 导出审计
- 客户导入接口后端限制为 admin / manager

## 部署状态

- Docker 生产镜像：已配置
- GitHub Actions：每次 `main` 自动进行 Vue/TypeScript build + `node --check` + Docker build
- 数据库：SQLite 验证/小规模部署；长期生产目标仍建议 PostgreSQL
- Docker DB：`/data/tradeflow.db`
- 数据卷：`tradeflow-data:/data`
- 附件卷：`tradeflow-uploads:/app/uploads`
- 备份目录默认：`/data/backups`
- Codespaces：适合开发、演示、验收，不应视作 24/7 生产服务器
