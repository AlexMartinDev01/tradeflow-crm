# TradeFlow CRM 需求模块进度矩阵

- ✅：核心业务需求已形成可操作闭环

## 当前已完成且容易被旧文档误判为“未完成”的功能

以下能力现在已经真实实现，不应再次作为待办重复开发：

- 客户组织树、母子公司、客户合并
- 联系人离职交接、生日/纪念日提醒
- 客户资料完整度、LTV、潜力评分
- 客户专属价、阶梯价、价格历史、市场适配规则
- 公海池、自动回收、领取、协同人
- 自定义字段必填/唯一/角色可见/可搜索规则
- 自定义联系方式渠道设计器
- 品牌多级经销网络
- 询盘自动分配、首次响应 SLA、输单原因
- 报价底价红线、低毛利/高折扣/特殊账期条件审批
- 合同工作台与合同版本
- HS Code、结构化报关资料
- 可审计汇率表与币种换算
- 部门级 self / department / all 数据范围
- 密码策略、登录失败锁定、强制改密、TOTP 2FA
- 客户回收站、恢复、永久清理
- SQLite 自动/手工备份与离线恢复脚本
- 敏感字段后端脱敏与客户导出权限
- SMTP 实际发送、Message-ID / 失败原因记录
- 营销邮件打开/点击追踪与 RFC 风格一键退订
- 客户批量修改与 10 分钟预览快照
- 客户数据质量中心
- 自定义 BI 报表设计器与 CSV 导出
- 白名单自定义自动化规则设计器
- 附件完整性扫描、快照与异地备份适配
- 运行状态/监控页面
- 售后知识库、历史方案推荐与一键复用

## 下一阶段优先级

1. **为移动端配置真实 OCR Provider 并做字段映射/识别准确率验收**
2. **Gmail OAuth / Outlook OAuth / WhatsApp Business / ERP / 电商平台真实授权集成**
3. **S3 / OSS 对象存储、病毒扫描与正式异地备份目标**
4. **PostgreSQL 迁移、正式生产部署、集中式监控与告警**
5. **海关/承运人/电子签章等外部正式业务接口**

> SMTP 用户名/密码方式的真实邮件发送已经实现；打开/点击追踪与一键退订也已经实现。后续“真实邮件能力”主要指 Gmail/Outlook OAuth 等账号级授权，而不是再次实现 SMTP。

> 外部服务类能力只有在获得真实账号、OAuth Client、API Key 或目标系统接口资料后才会标记为“已接通”；仅存在配置入口不算完成。
